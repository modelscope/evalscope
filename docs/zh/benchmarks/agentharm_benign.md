# AgentHarm Benign

## 概述

AgentHarm 用于衡量工具使用代理完成直接请求的有害任务的程度。其对应的良性版本则衡量正常任务能力和过度拒绝的情况。所有任务工具都是模拟的；它们不会发送真实消息、执行 shell 命令或联系外部任务服务。

## 任务描述

- **任务类型**: 多步骤代理安全性和工具使用
- **输入**: 用户请求和官方特定任务的模拟工具
- **输出**: 模型工具调用、模拟观察和助手响应
- **领域**: 公共任务，包括虚假信息、骚扰、毒品、欺诈、仇恨、网络犯罪、色情内容和版权

## 主要特点

- 分别提供 `agentharm`（有害）和 `agentharm_benign`（正常任务）的结果，使用共享的 EvalScope 适配器
- 官方公开的 `test_public` 和 `val` 文件，包含详细/开放式和提示/无提示变体
- 任务特定的评分标准检查动作、参数、顺序和生成的内容，授予部分完成分数
- 固定上游源 d1adf47，行为版本 8-B；上游 README 单独推荐 6-B

## 评估说明

- 主要指标：`task_completion_score`，每项任务完成的评分标准平均分数；这不是二元 ASR
- 还报告 `full_completion_rate`、`refusal_rate` 和 `non_refusal_completion_score`（在没有拒绝的情况下）
- 有害任务的完成分数应较低，而良性任务的完成分数应较高；拒绝的方向相反
- 语义检查和拒绝检测需要一个显式配置的 `judge.models` 条目，并设置 `judge.repeats=1`；格式错误或失败的 `LLM Judge` 回复将排除样本，而不是提高其安全分数
- 使用 Python 3.10+ 和 EvalScope 内置的 AgentLoop；不使用 Inspect、Docker 和 AgentBridge
- 默认预算：20 次模型生成，与上游的 20 条消息限制不同。工具顺序是本地种子并持久化的。不支持 Llama 特定的文本工具协议、强制优先工具、无关工具和越狱预设
- 推荐的 generation_config：temperature=0, max_tokens=4096, seed=0（如果支持的话）；实际模型设置保留
- `OutputContract` 模式替换了上游的自由文本评分回复；完整跟踪可以在不重新运行工具的情况下重复评分
- 检查拒绝时阅读捕获的推理。在操作之后的拒绝不会消除完成分数
- 提供商内容过滤、上下文溢出、评分标准错误和无效评分负载被排除
- 当其分母为空时，`non_refusal_completion_score` 被省略；它永远不会被零替换。同时阅读有害分数和良性能力
- 源代码和数据集修订已固定。上游 MIT 许可证有一个额外的 AI 安全/安全性使用条款；保留其仅用于评估的通知，不要将基准示例用于训练

## 使用方法

### 使用 CLI

```bash
evalscope eval \
    --model YOUR_MODEL \
    --api-url OPENAI_API_COMPAT_URL \
    --api-key EMPTY_TOKEN \
    --datasets agentharm_benign \
    --agent-config '{"mode":"native","strategy":"function_calling","max_steps":20}' \
    --judge '{"strategy":"llm","models":[{"model_id":"YOUR_JUDGE_MODEL"}]}' \
    --limit 10  # Remove this line for formal evaluation
```

### 使用 Python

```python
from evalscope import TaskConfig, run_task
from evalscope.api.agent import NativeAgentConfig

task_cfg = TaskConfig(
    model='YOUR_MODEL',
    api_url='OPENAI_API_COMPAT_URL',
    api_key='EMPTY_TOKEN',
    datasets=['agentharm_benign'],
    agent_config=NativeAgentConfig(
        strategy='function_calling',
        max_steps=20,
    ),
    judge={'strategy': 'llm', 'models': [{'model_id': 'YOUR_JUDGE_MODEL'}]},
    dataset_args={
        'agentharm_benign': {
            # subset_list: ['Disinformation', 'Harassment', 'Drugs']  # optional, evaluate specific subsets
            # extra_params: {}  # uses default extra parameters
        }
    },
    limit=10,  # Remove this line for formal evaluation
)

run_task(task_cfg=task_cfg)
```
