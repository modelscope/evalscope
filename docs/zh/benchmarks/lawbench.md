# LawBench


## 概述

LawBench 评估中文法律知识和推理能力，涵盖记忆、理解与应用三个层面。此集成支持 19 项任务，包括法律考试、案例分析、信息抽取和法律咨询。有关该基准测试及论文详情，请参阅[官方项目](https://github.com/open-compass/LawBench)。

## 任务描述

- **任务类型**：法律问答、分类、抽取与生成
- **输入**：带有任务指令的中文法律问题或文档
- **输出**：按请求格式生成的中文回答
- **领域**：中国法律知识及法律推理

## 主要特点

- 支持 9,500 个样本，每项任务 500 个；可通过子集 `1-1`–`1-2`、`2-2`–`2-10` 和 `3-1`–`3-8` 选择特定任务
- 任务组覆盖法律知识、文档理解和实际应用
- 数据自动从 [ModelScope](https://modelscope.cn/datasets/evalscope/LawBench) 下载
- 使用官方的任务特定评分规则；无需 LLM 裁判

## 评估说明

- 对 19 项任务进行零样本（zero-shot）评估；不支持文档校对任务 (`2-1`)。
- 通过 `pip install 'evalscope[lawbench]'` 安装依赖。若需离线使用，请将 `local_path` 设置为 ModelScope 数据集快照路径。
- `lawbench_score`：分数越高越好（通常为 0–1；刑期预测分数可能为负）。总体得分为所有已评估任务的未加权平均值。
- `abstention_rate`：指未提取出有效答案的回答占比。官方排除的参考答案不计入评分。

## 使用方法

### 使用 CLI

```bash
evalscope eval \
    --model YOUR_MODEL \
    --api-url OPENAI_API_COMPAT_URL \
    --api-key EMPTY_TOKEN \
    --datasets lawbench \
    --limit 10  # 正式评估时请删除此行
```

### 使用 Python

```python
from evalscope import run_task
from evalscope.config import TaskConfig

task_cfg = TaskConfig(
    model='YOUR_MODEL',
    api_url='OPENAI_API_COMPAT_URL',
    api_key='EMPTY_TOKEN',
    datasets=['lawbench'],
    dataset_args={
        'lawbench': {
            # subset_list: ['1-1', '1-2', '2-2']  # 可选，用于评估特定子集
        }
    },
    limit=10,  # 正式评估时请删除此行
)

run_task(task_cfg=task_cfg)
```
